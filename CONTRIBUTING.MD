# Contributing to Anti-Nastya Club

First off, thank you for taking the time to contribute! 🎉 

## How to Can I Contribute?

### Reporting Issues
If you find a bug, please create a new issue detailing:
* Your browser and operating system.
* Steps to reproduce the bug.
* Screenshots or error logs (if applicable).

### Proposing New Features
If you have an idea for a new feature or improvement:
1. Open an issue to discuss your proposal.
2. Once approved, fork the repository.

---

## Local Development Setup

To run this project locally for development or testing, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/vintonDev/anti-nastya-club.git
2. **Install dependencies:**
    ```bash
    npm install
3. **Launch the backend server:**
    ```bash
    node server.js
4. **Open in browser:**
    Navigate to http://localhost:3000 to view the store.

---

## Pull Request Process
1. Create a new branch for your feature (`git checkout -b feature/amazing-feature`).
2. Commit your changes (`git commit -m "Add some amazing feature"`).
3. Push to the branch (`git push origin feature/amazing-feature`).
4. Open a Pull Request on GitHub.
